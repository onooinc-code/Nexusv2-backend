# Mobile & Accessibility Components

## 1. NxBottomSheet
- **File**: `components/mobile/NxBottomSheet.tsx`
- **Description**: Touch-friendly slide-up panel for mobile actions.
- **Requirements**:
  - Snap points (40%, 90%).
  - Drag handle with velocity-based closing.

## 2. NxFab
- **File**: `components/mobile/NxFab.tsx`
- **Description**: Floating Action Button for primary hub actions.
- **Requirements**:
  - Expands to show secondary actions on long-press or tap.

## 3. NxLiveRegion
- **File**: `components/a11y/NxLiveRegion.tsx`
- **Description**: ARIA live region for screen reader announcements.
- **Requirements**:
  - Automatically announces system notifications and agent status changes.
