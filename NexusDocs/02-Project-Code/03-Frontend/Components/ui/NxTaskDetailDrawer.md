# NxTaskDetailDrawer

## Specification
- **File**: `components/drawers/NxTaskDetailDrawer.tsx`
- **Width**: 560px
- **Aesthetic**: Detailed information panels with frosted glass backgrounds.

## Features
- **Trace Identity**: Shows `trace_id` with a one-click copy button.
- **Status Timeline**: Vertical progression of task states (Pending -> Running -> Completed/Failed).
- **Log Accordion**: Collapsible sections for each execution step's detailed logs.
- **Payload Viewer**: Raw JSON viewer for input/output data with "Copy to Clipboard" functionality.
