# P3 Specialized Features

## 1. NxActivityHeatmap
- **File**: `components/modules/contacts/NxActivityHeatmap.tsx`
- **Description**: GitHub-style activity heatmap for 52 weeks of contact interactions.
- **Requirements**:
  - Color intensity based on interaction count.
  - Column-by-column fade-in animation.

## 2. NxVersionHistory
- **File**: `components/modules/contacts/NxVersionHistory.tsx`
- **Description**: Accordion view showing the evolution of AI "beliefs" or contact data over time.
- **Requirements**:
  - Strikethrough for superseded entries.
  - Inline diff popover.

## 3. NxMemoryDiff
- **File**: `components/modules/memory/NxMemoryDiff.tsx`
- **Description**: Visual comparison between two memory states during consolidation.
- **Requirements**:
  - Highlighted additions (green) and removals (red).
