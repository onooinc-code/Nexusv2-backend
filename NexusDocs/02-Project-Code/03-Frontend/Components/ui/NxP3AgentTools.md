# P3 Agent Specialized Tools

## 1. NxAgentCompare
- **File**: `components/modules/agents/NxAgentCompare.tsx`
- **Description**: Side-by-side comparison of different agent models or configurations.
- **Requirements**:
  - Radar chart overlay for capability comparison.

## 2. NxAgentWorkloadChart
- **File**: `components/modules/agents/NxAgentWorkloadChart.tsx`
- **Description**: Stacked bar chart showing task distribution across the agent pool.

## 3. NxSemanticCluster
- **File**: `components/modules/memory/NxSemanticCluster.tsx`
- **Description**: 2D scatter plot visualization of semantic memory clusters.
- **Library**: ECharts (Scatter GL).
