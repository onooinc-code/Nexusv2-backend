# P2 Modals & Drawers

## 1. NxQueueModal
- **File**: `components/modals/NxQueueModal.tsx`
- **Description**: Table view of current and historical background jobs.
- **Features**:
  - Actions: Pause, Retry, Cancel.
  - Optimistic UI updates.

## 2. NxMemoryConsolidationModal
- **File**: `components/modals/NxMemoryConsolidationModal.tsx`
- **Description**: Diff-style view for AI memory merging.
- **Features**:
  - Before/After split view.
  - Manual edit capability before confirmation.

## 3. NxProviderHealthModal
- **File**: `components/modals/NxProviderHealthModal.tsx`
- **Description**: Connectivity tester for AI providers (OpenAI, Anthropic, etc).
- **Features**:
  - Real-time latency pinging.
  - Model capability checklist.
